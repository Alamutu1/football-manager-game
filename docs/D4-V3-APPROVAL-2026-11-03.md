# D4 v3 Approval — 3 Nov 2026

User decision, recorded verbatim in substance: "I officially approve D4 v3."
The user thanked the team for preserving previous versions, keeping the
save structure unchanged, and completing the calibration without manually
inflating individual players. That is the approval basis, and it is kept
here so a later session does not have to re-derive it.

## What was approved
- D4 calibration v3, model version d4-v3, as implemented in
  `src/game/ratings.ts` on 3 Nov 2026 and reported in
  `docs/D4-CALIBRATION-V3-REPORT-2026-11-03.md`.
- The calibration method: formula-wide changes only (goalkeeper weight
  0.65 → 0.50, role prime-mean alignment, signature ±9 → ±6 with
  strength/weakness ±7..13 → ±5..9, goalkeeper decline after 33
  steepened). No player-specific exceptions, no hand-edited stars.

## Phone verification before approval
- Temporary preview: https://animated-piroshki-89dbc0.netlify.app/squad
  (static export, bundle verified to contain d4-v3 and no d4-v2 stamp).
- User-reported result: all five Android phone tests passed.
  The five tests were the Stage 1 / v3 check set: Squad page loads,
  Squad/Formation switch, view-only note, shirt → Profile, and
  expanded profile shown in the Squad List.
- Spot checks on that preview, consistent with v3: Kevin Müller
  (Heidenheim, GK, age 35) 71 est. in v3 vs 81 in v2; Formation Best XI
  rating 68; club average rating 67.

## What was preserved, and what was not changed by approval
- Original D4 v2: preserved in `docs/D4-REPORT.md`,
  `docs/D4-DESIGN.md`, `docs/D4-CALIBRATION-AUDIT-2026-11-03.md`,
  and the full backup `~/workspace/pcm-d4v2-backup-2026-11-03.zip`.
- Save structure: unchanged. GameState, storage and store files are
  untouched since 2 Nov 2026; existing saves load and pick up v3
  ratings on load.
- Phase C database items (duplicate Mbappé, missing Salah/Vinícius
  Júnior/Rodri, generic positions) were NOT approved or implemented
  by this decision. They remain a separate proposal in
  `docs/D4-DATABASE-PROPOSAL-2026-11-03.md`, each option needing
  its own decision.
- D5 was NOT started by this decision. Tactics were NOT changed.

## Standing future requirements recorded with this approval
- Formation changes and genuine tactical freedom remain essential
  future requirements (formation selector, XI/bench selection, roles,
  saved tactics, engine use of user tactics). They are NOT part of
  D5's season skeleton unless the user explicitly adds them.
- Background music with an ON/OFF option in Settings must remain on
  the roadmap. It is NOT part of D5 unless the user explicitly adds it.
